# 全簇补样并分离采样与分组效应

用户确认三天内的cluster对照使用同Subzone内150 m住宅邻接连通分量，保留孤栋，不称真实小区。保留400 m代表住宅样本A，为漏采簇增补真实住宅形成共同对照样本B，交付A→Subzone、B→Subzone、B→cluster；后两组使用同一位置与点级分数，前两组报告补点影响，避免同时换样本与分组却声称只测聚合。

采用A拟合的同指标标准化参数，补点不重新拟合；两种分组都公布90%有效测量覆盖、50%计划样本已验证可行门槛及合格样本均分，低样本量显著标记。150 m是工作假设，连通可产生长链与跨障碍合并；需要地图诊断并报告规模。Day 1估算补点和路由预算，同一位置/终点/时段仅查一次。该决定优先覆盖所有已定义簇并记录采样代价，不采用遗漏簇却默认其低分或复制邻近实测值的做法。
