# 正式推荐使用 Subzone，住宅簇作为对照

用户于 2026-10-16 确认，正式结果为 Top 5 不同官方 Subzones，住宅簇作为空间敏感性对照。报告结构已使用 Subzone，现有数据提供 332 个有完整编码和名称的 Subzones；住宅名称不完整，HDB 建筑多边形也不是现成小区边界。采用官方分区可固定结果名称及比较对象，同时保留住宅簇对照来检查区内差异及聚合影响。

这项决定不代表每个 Subzone 的所有住宅都满足用户约束；结果需要另报被分析位置的覆盖范围、可行数量与比例。住宅簇不能未经核查就称真实小区，改变分区时也不能直接以不同区域 ID 计算 Top-5 Jaccard。
