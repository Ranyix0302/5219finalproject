# 三天基线采用现有住宅、代表位置与透明邻近性代理

用户确认两天首版以经核查的现有住宅建筑作为候选底表，在固定 400 m 网格中选取真实住宅代表点，计算至核准 NUS AS8 终点的通勤及七维指标，再推荐 Subzones。MRT 出口直线距离、公交站数、图书馆直线距离、公园面邻近距离可作为明确标注的代理，不能冒充完整步行网络可达性。URA 掩膜留作后续范围核查，方法口径需要与原 proposal 的规划住宅范围区分。

这取舍针对现有近 9.7 万条住宅记录、仅 5 条通勤示例与三天投入窗口，避免假装全量住宅、多校园和步行网络已经完成。Subzone 必须有至少一半计划样本已验证满足全部硬约束才进入排名，按合格样本平均分排序；50% 是预先选定的业务规则而非实证最优值。cluster 对照同样必须在三天交接前完成，250/500 m 全套路由与 distance decay 可延后；cluster 定义及采样覆盖细则另行确认。
