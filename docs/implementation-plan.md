## 3. 核心判断

三天窗口内，优先完成可复现的简单基线。主要工作量在输入定义、数据清理、通勤覆盖和空间汇总；加权求和本身很小。先建立正确的指标含义，再处理参数和稳健性。标准化不能修复测量定义，敏感性也不能证明概念合理。

不得用“静态指标先挑分最高的若干栋，然后只查它们的通勤”冒充全域七维最优：尚未查通勤的住宅可能更优。若需要减少请求，采用事先规定、覆盖研究范围的采样设计，并公开其局限，不按想要的分数选择路由样本。

## 5. 输入整理：先形成可靠的一张底表

### 5.1 住宅与来源

优先保留 B 现有 `Residential_ID` 作为冻结交接版本的来源键，另建模型内部 `building_id` 和映射表；B 的编号按合并行序生成，重新排序/导入可能改变，不能当永久天然 ID。

合并 `POSTAL_COD` / `POSTALCODE` 为保留前导零的六位字符串。107 个跨来源同邮编的记录进入冲突表，结合来源、地址和坐标审查；不要未经核查自动双计。不同邮编的共址记录保留并标记，不能只按坐标删除。最终记录数在消解后报告，不预先保证等于某个数。

区分 HDB、Landed、Non-Landed、EC、未知，并核查建筑用途是否确为住宅；图层名称和邮编不能单独证明全部记录符合住宅候选条件。住宅点或地址点不是住户人数权重；大量 Landed 点不能被解释为大量学生可租机会。B 的点与 A 的中心点生成方式存在差别，需保留坐标来源，不互相覆盖后继续沿用旧指标。

### 5.2 几何、空间范围与位置

在派生副本修复 2 条无效公园面及 6 条无效 Subzone；记录修复前后数量和类型。所有距离/缓冲/面积统一至 EPSG:3414，显示时转回 WGS84。

现有 GDB 没有交付 URA MP2025 候选住宅面。你已确认首版以已交付且经核查的现有住宅记录作为研究范围，URA 用于后续核查；因此不以 Subzone 边界冒充住宅掩膜，也不声称首版已覆盖 proposal 的全部规划住宅用地。报告/PPT 方法口径需随实际实现更新。

首版使用代表住宅点：网格原点、400 m 尺寸、选择规则、Subzone 边界处理和簇覆盖补点规则按第14节写入配置；不可跨 Subzone 边界把有住宅的分区漏掉，也不把代表点分数复制成每栋楼的实测结果。Day 1 生成原样本A与簇覆盖样本B，在路由前冻结清单，解决小 cluster 没有400 m样本的问题。

### 5.3 设施供给单位

医疗层有共址诊所，超市有共址牌照。先区分“牌照数”“服务地址数”和“设施数”，再选择计数单位并记录映射；不要把所有共址都视为重复，也不要把全部牌照都视为独立服务机会。超市部分为地址级匹配，保留精度标记。站点需检查运营状态，不能将尚未开放站点视为已可使用。

## 6. 七维基线：先解释含义，再选择算法

下表是你已接受的简单基线。800 m/1 km 来自旧计划，是待检验的工作假设，并非已校准的学生行为参数；计数单位和公园纳入类别按第14节已确认配置实施。

| 维度 | 首版建议字段/测度 | 方向 | 实际含义与局限 | 对照或改进 |
|---|---|---|---|---|
| 校园通勤 | `campus_transit_min`：同一工作日/出发时刻到已核准终点的公共交通时长 | 越小越好 | 特定目的地和时刻；第一条 API itinerary 不等于所有人的最优出行体验 | 另一时段；核查步行/候车/车程构成 |
| MRT/LRT | `rail_exit_euclid_m`：至运营出口的直线距离 | 越小越好 | 空间邻近性，不能称步行分钟 | 典型点的步行网络或路线复核 |
| 公交供给 | `bus_stops_800m`：800 m 内去重站点数 | 越大越好 | 站点供给，不代表路线、频率、容量 | 半径变化；有数据后引入线路供给 |
| 日常购物 | `supermarket_sites_800m`：800 m 内超市服务点数 | 越大越好 | 仅日常采购机会，不能说覆盖商场/餐饮全部服务 | 最近超市距离或替代半径 |
| 学习资源 | `library_euclid_m`：最近公共图书馆直线距离 | 越小越好 | 图书馆邻近性，不代表座位、开放时间和真实步行路线 | 网络距离抽样对照 |
| 医疗服务 | `clinic_sites_1000m`：1 km 内预先定义的诊所服务点数 | 越大越好 | 附近基础供给，不代表医疗质量和对学生适用程度 | 最近诊所距离；许可点/地址点计数对照 |
| 绿色空间 | `park_proximity_euclid_m`：住宅点至允许纳入的公园面的距离；园外为最近边界距离，园内为 0 | 越小越好 | 几何邻近，不代表合法入口或可进入性；需定义自然保护区/走廊 | 1 km 内公园面积；centroid 仅作为测量偏差对照 |

Hawker/Gym 保留为背景或扩展，不自动挤入七维、替代超市或增加用户权重。公园边界距离与绿地面积表达不同构念，不能因为两者相关就认定可互换。MRT/公交 KDE 也不与距离/站数重复加权；只有服务含义明确后才列对照。

为每个指标写一行“学生需要什么 → 当前测度能表达什么 → 未表达什么 → 参数依据/假设 → 验证证据”。绘制缺失率、分布、零值比例和 Spearman 相关图；零方差/严重饱和/高相关触发复查，不能自动以删列或标准化掩盖。

## 7. 确定性的 MCDA 与区域输出

1. 固定数据、目的地、路线场景与分析位置，保存 `dataset_version` 和 `analysis_version`。
2. 在固定基线样本上拟合 P5/P95，截尾后映射到 0–1，成本型反向。权重或用户通勤上限变化时不重新拟合。P5=P95 时停止使用未定义列，明确提示并按预先确认规则处理，不偷偷改权重。
3. 检查权重有限、非负、合计为 1；全零拒绝。用户比例需要归一化时明确显示实际应用的权重。
4. 使用**原始分钟/距离**检查硬约束，不能用截尾值来判断是否可行。缺失和路线错误单独标记，不把未观测当不满足行为偏好。
5. 对可行分析点计算 `score_i = Σ w_j z_ij`，保留每个 `contribution_ij = w_j z_ij`。
6. Subzone/cluster 使用可行样本平均分，并用同一批点聚合贡献；要求至少90%计划样本有有效七维测量，且至少50%计划样本已验证满足所有硬约束。有效样本少于3时显著标记支持有限，避免极少位置支撑整区的强结论。
7. 分别输出该区计划样本数 `n_planned`、测量有效数 `n_valid`、可行数 `n_feasible` 与得分离散程度。测量覆盖率定义为 `n_valid/n_planned`，条件可行比例为 `n_feasible/n_valid`，已验证可行比例为 `n_feasible/n_planned`；分母为零时返回未定义状态，不填 0%。已确认区域资格的 50% 使用 `n_feasible/n_planned`；未知点不算已验证可行，也不等同真实不可行。另报空间采样覆盖（如住宅所在 Subzone 是否都有样本），不能与路线测量覆盖混为一谈。不能只展示条件可行比例、隐去接口失败和测量覆盖，制造“全区满足条件”。
8. 排序取五个不同 Subzones；不足五个则如实返回。以完整精度分数降序排序；完全同分按同一可行样本的原始通勤均值、MRT距离均值，再按稳定area_id排序。cluster对照使用相同规则。
9. 解释原始值、标准化值与加权贡献；贡献小可能由权重小造成，不等于设施表现差。区域均分代表被分析且可行位置的平均，不保证整区所有建筑都符合条件。

首版不得纳入演示页 green space 的 0.4、0.9 等教学假数。它们没有真实 GIS 测量来源。

## 8. 实验：区分测量定义、参数和偏好

### 必须先做的三类验证

- **概念**：检查每项测度与设施功能/学生需求是否相符；写出替代测度不能覆盖的含义。
- **测量**：空间位置、去重单位、CRS、运营状态、目的地与路线抽样；至少 20 条路线覆盖远近/高低分/边缘样本，使用相同目的地和时段，记录核查方式。
- **统计**：缺失、分布、异常、零值/饱和、变异和冗余。相关高不自动证明重复，也不自动说明应该删掉某项。

### 实验优先级与输出

| 优先级 | 实验 | 改变什么 | 固定什么 | 最少输出 |
|---|---|---|---|---|
| P0 | 四个偏好情景 | Commute/Transit/Lifestyle/Balanced 权重 | 数据、目的地、硬约束、标准化、区域资格 | 4 张统一图例地图或比较图、排名表、Top-5 Jaccard |
| P0 | ≥1,000 次权重模拟 | 预先声明分布下的合法权重 | 同一矩阵、有效集合和汇总规则 | Top-5 入选频率、排名分布、随机种子/分布配置 |
| P0 | OAT | 单个目标权重，其余按比例缩放 | 其他实验条件 | 权重—得分/名次曲线、切换区间 |
| P1 | 设施半径 | 若开展扩展，先登记替代半径再运行，不按结果择优选参 | 数据与偏好 | 指标变化、排名变化、Jaccard |
| P1 | 公园定义 | 边界距离 vs 周边公园面积；必要时 centroid 偏差诊断 | 同一研究范围和偏好 | 差异地图、原始值比较、概念含义说明 |
| 后续扩展 | 空间采样 | 400 m vs 250/500 m，重算前登记扩展参数与请求预算 | 目的地/时段/设施定义，优先应用基线标准化参数 | 同名 Subzone 分数/排名差、采样覆盖与请求量 |
| P1 | 聚合规则 | 均值 vs 中位数；区域资格门槛 | 同一有效点集 | 贡献可加性检查、排名变化、局限 |
| P0（三天必做） | 住宅簇对照 | 已定义并可解释的 cluster membership | 同一分析点、偏好与点级得分 | 两套区域结果；统一位置/建筑集合上的空间覆盖比较；样本支持与边界局限 |
| 扩展 | Distance decay | 明确的半衰距离/β | 数据、指标构念及可比实验设置 | 与 buffer 的差异及参数敏感性 |

cluster 已由你明确列为三天交接必做，因此 Day 1 就要定义并检查 membership 与样本覆盖，不能等 Day 3 才发现缺少小簇通勤。其余P1项按剩余时间选择；250/500 m全套路由和distance decay延后。cluster使用第14节已确认的150 m连接规则，不为了好看的结果临时画“小区”边界。

### 实验的技术边界

- 首先确定正式基线；实验参数在看排名前登记，不按结果挑最稳定的一组。
- 只改权重时保持归一化参数、有效点与硬约束固定。若资格规则依赖权重，需先改成固定规则，或明确它同时改变了候选集合。
- 计算 Top-5 Jaccard 时比较相同区域体系；它只测名单重叠，不测顺序。Spearman/Kendall 使用共同可比较区域，并报告交集大小/缺失情况。
- 改成 clusters 后不能直接比较 Subzone ID 与 cluster ID，需映射到共同位置或住宅集合，分别讨论名单与空间覆盖。
- 同一指标下的权重、采样、分组与半径实验应用冻结的基线标准化参数；若替代测度改变构念或单位（例如公园距离改公园面积），必须在A样本上为新测度另拟合并保存版本化参数，明确这是测度与相应标准化的联合变化，不能用米制距离的上下界归一化平方米面积。
- 若用 `exp(-βd)`，可通过 `β=ln(2)/d50` 解释半衰距离；d50 仍是需要依据或披露的假设，不因公式平滑就客观。
- 稳定性结论只适用于所测试的假设范围，不证明指标代表学生真实偏好，也不把模拟入选频率称现实选择概率。

### 14.1 可复现的分析簇与公平对照

采用简单的空间连接规则：在同一 Subzone 内，对去重且核查用途后的住宅点，若两点直线距离不超过150 m就连一条边；相互连通的住宅组成一个分析簇。HDB、Landed、Non-Landed、EC使用同一规则，保留住房类型作为属性，不人为分成不同排名池；孤立住宅也保留为单栋簇。

150 m是已接受的工作假设，不是小区真实边界或行为验证结果。链式相连可使整簇跨度远大于150 m；道路、河流和行政边界也可能造成错误合并或切分。必须报告建筑数、空间跨度、住房类型组成，并在看分数前做地图抽查。100/200 m可做低成本的簇数量/形态诊断；该诊断不等于已为替代簇完成完整推荐实验。不根据哪套规则产出更好看的Top 5来选择半径。

**样本与路由：**

1. 保留原 400 m 基线样本清单 A；网格使用 EPSG:3414 固定原点 (0,0)，边界网格按 Subzone 分层，每个有住宅的网格×Subzone 选最靠近网格中心的真实住宅，距离并列按稳定 building_id 选择。
2. 在全量住宅上构建簇之后，检查每簇是否有 A 中样本；对没有样本的簇，增补一个最接近该簇点集中心的真实住宅。此为最低覆盖，不宣称一个点足以代表大簇的全部内部差异。
3. A 加上去重后的补点形成共同对照样本 B。补点方案在路由前冻结，不能按高低分或是否满足通勤上限选择；同一位置/终点/时段只查询一次并缓存。
4. 用 A 拟合标准化参数，应用到 A 与 B；补点不重拟合上下界。先形成 A 的 Subzone 正式基线，再分别对 B 按 Subzone 和 cluster 汇总。
5. 必须交付三组结果：**A→Subzone、B→Subzone、B→cluster**。前两组检查增补样本效应；后两组在相同位置、权重、原始指标、标准化分数上检查分组效应。主空间对照固定均衡权重与60 min通勤上限，不能在三组之间改变上限；无上限的正式评分基准另存。
6. 不把 B 的补点追加到 A 后继续声称正式基线仍为原400 m样本。B 也不代表按住户人数、建筑容量或土地面积加权的无偏估计；它是为覆盖分析簇而构造的对照样本。

**对照与展示：**

- cluster 使用可追溯的稳定成员表及所属 Subzone 命名，例如“某 Subzone · 分析簇 C012”，不凭空补真实小区名；地图显示成员住宅/代表位置，不把任意凸包当作真实小区边界。
- cluster沿用Subzone的50%计划样本可行门槛及合格样本均分，并同时应用第14.2节的90%有效测量覆盖门槛；另报测量完整度和样本量。单点簇/低样本簇标记支持有限，不将其总分精度说成高可靠度。
- 不以不同区域 ID 直接计算 Jaccard 或 Spearman。对共同样本 B，标记其是否位于各方案推荐的 Top 5 区域，比较位置集合的重合，并报告推荐位置数、涉及建筑数、区域尺度与样本支持。
- Top-5 cluster 覆盖位置通常比 Top-5 Subzones 少，重合低可能只是区域大小不同；它不能单独证明模型不稳健或哪个分组更好。
- Day 1 先根据真实簇数、补点数和路由试跑估计额外请求；新增路由计入三天预算。若外部接口中断导致不能完成，按受阻事实和完成覆盖交接，不把未测簇结果补成零或编造完整对照。

这一设计需要补充路由，具体数量目前未知；它让每个已定义cluster都有明确计划样本，同时通过B→Subzone对照解释补点影响。严格复用A、仅评价已有样本簇的备选方案未被采用，不能在实施时静默替换为它以声称完成全簇对照。

| OAT | 以均衡情景为基准，目标权重取0.05–0.60，步长0.05，其余按原比例缩放 | 同一硬约束和候选输入；报告切换区间，不称精确临界点 |
| Monte Carlo | 均衡权重为中心，Dirichlet `κ=50`，1,000次有效扰动，固定seed=42 | 所有基准权重大于0；保存每次权重/排名；频率仅针对该分布，不是居民选择概率 |
| 资格对照 | 在固定60 min通勤上限和均衡权重下，将50%可行门槛对照25%/75%；其余条件含90%测量覆盖门槛固定 | 与只改偏好权重的实验分开。默认无上限时该门槛对照可能退化为完全相同，只作功能检查，不能据此声称稳健。若60 min下也无差异，如实报告相应可行比例分布；不得为制造差异事后换上限 |
| 三天必做 | 四情景、OAT、1,000次扰动、20路线复核、cluster对照、接口交接 | 半径/公园面积/均值中位数对照按剩余时间做；250/500m全套路由、distance decay、多校园后续再做 |

完整度与样本支持条件在 Subzone/cluster 两种分组中同样公布；不同分组导致有效区域集合不同是实验结果的一部分，应报告而不是静默求相关。40/60 min 功能试验可复用同一通勤快照，不新增路由。
